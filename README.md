# 🌿 Prana Yoga Studio — Мобильное приложение (iOS & Android)

Премиальное кроссплатформенное мобильное приложение для йога-студии, созданное на **React Native + Expo** с поддержкой iOS, Android и Web.

---

## 📱 Функционал приложения

1. **Интерактивное расписание (Календарь)**:
   - Выбор дней недели (Сегодня, Завтра и дни вперед).
   - Фильтры по стилям йоги (*Хатха, Виньяса, Аэройога в гамаках, Инь-йога, Аштанга, Sound Healing*).
   - Индикация свободных мест в реальном времени, уровня сложности и зала.
2. **Система записи и бронирования**:
   - Запись в 1 клик со списанием с активного абонемента или выбором разовой оплаты.
   - Запись в **Лист ожидания (Waitlist)** при заполнении группы.
   - Правила отмены занятий и защита от овербукинга.
3. **Электронный пропуск с QR-кодом**:
   - Каждый билет генерирует динамический QR-код для мгновенного чек-ина на ресепшн или у входа в зал.
4. **Магазин абонементов**:
   - Тарифы: Пробное занятие, 8 практик, 12 практик, Безлимит на месяц.
   - Отображение включенных опций (аренда ковриков, гостевые визиты, заморозка).
   - Моделирование онлайн-оплаты и мгновенная активация.
5. **Профили преподавателей**:
   - Подробные визитки мастеров: сертификаты, опыт, рейтинг, отзывы, направления.
6. **Личный кабинет**:
   - Статистика посещений и часы в практике, непрерывный стрик.
   - Управление push-напоминаниями за 2 часа до тренировки и SMS.
   - Адрес, схема проезда, контакты и правила студии.

## 🚀 Как запустить приложение

### 1. Запуск в браузере (быстрый предпросмотр)
```bash
npm run web
```
Приложение откроется в браузере с адаптивным мобильным интерфейсом.

### 2. Запуск на iPhone или Android (реальный телефон)
1. Установите бесплатное приложение **Expo Go** из App Store (iOS) или Google Play (Android).
2. Запустите проект на компьютере:
   ```bash
   npm start
   ```
3. Отсканируйте появившийся в терминале QR-код:
   - **На iPhone**: стандартной камерой iOS -> нажмите всплывающее уведомление для открытия в Expo Go.
   - **На Android**: через сканер внутри приложения Expo Go.
4. Приложение загрузится и будет работать на вашем смартфоне с нативной производительностью!

## 🏗 Архитектура проекта

```
├── app/
│   ├── _layout.tsx           # Корневой стек навигации и контекст
│   ├── (tabs)/
│   │   ├── _layout.tsx       # Нижняя панель вкладок (Tabs)
│   │   ├── index.tsx         # Расписание (Schedule)
│   │   ├── bookings.tsx      # Мои записи и QR-билеты
│   │   ├── memberships.tsx   # Абонементы и покупка
│   │   ├── instructors.tsx   # Преподаватели студии
│   │   └── profile.tsx       # Профиль и настройки
│   └── class/[id].tsx        # Экран детальной информации о тренировке
├── src/
│   ├── constants/
│   │   └── theme.ts          # Цветовая гамма, шрифты, отступы, тени
│   ├── context/
│   │   └── AppContext.tsx    # Управление состоянием (брони, абонементы)
│   ├── data/
│   │   └── mockData.ts       # База данных классов, преподавателей и тарифов
│   ├── types/
│   │   └── index.ts          # TypeScript интерфейсы
│   └── components/
│       ├── Header.tsx        # Заголовок с аватаром
│       ├── DaySelector.tsx   # Календарная лента дней недели
│       ├── CategoryFilter.tsx# Фильтр направлений йоги
│       ├── ClassCard.tsx     # Карточка тренировки
│       ├── BookingModal.tsx  # Модалка записи
│       ├── QrModal.tsx       # Электронный QR-пропуск
│       ├── MembershipCard.tsx# Карточка абонемента
│       ├── InstructorCard.tsx# Профиль мастера
│       └── Toast.tsx         # Всплывающие уведомления
├── app.json                  # Конфигурация Expo (iOS/Android bundle IDs)
└── package.json
```

## 📲 Публикация в App Store & Google Play

Для создания финальных установочных файлов:
- **Android APK / AAB**: `npx eas build --platform android`
- **iOS IPA (App Store)**: `npx eas build --platform ios`
